# 模型管理 (Model Management)

模型管理模块负责维护具体 AI 模型的元数据、定价和启用状态。它是系统中“模型路由”和“计费预估”的基础。

## 1. 数据模型定义

### 数据库表：`ai_model`
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | BIGINT | 自增主键 |
| `provider_id` | BIGINT | 所属供应商 ID (外键) |
| `model_id` | VARCHAR(255) | 供应商原始 ID (如：`gpt-4-turbo`) |
| `name` | VARCHAR(255) | 自定义显示名称 |
| `description` | TEXT | 模型描述 |
| `context_window` | INT | 上下文窗口限制 (Tokens) |
| `input_price` | DECIMAL(15,10) | 输入 Token 价格 (USD/Token) |
| `output_price` | DECIMAL(15,10) | 输出 Token 价格 (USD/Token) |
| `is_enabled` | BOOLEAN | 是否启用 |
| `capabilities` | JSON / VARCHAR | 支持的能力 (CHAT, IMAGE, VISION 等) |

## 2. API 接口设计

### 核心 API 端点
| 动作 | 路径 | 方法 | 说明 |
| :--- | :--- | :--- | :--- |
| 查询列表 | `/api/models` | GET | 返回所有已配置的模型及其关联的供应商信息 |
| 更新/创建 | `/api/models` | POST | 允许手动配置模型或修改自动发现的模型 |
| 批量启用/禁用 | `/api/models/batch-toggle` | POST | 快速管理模型状态 |

### 响应示例 (GET `/api/models`)
```json
[
  {
    "id": 1,
    "name": "GPT-4o",
    "modelId": "gpt-4o",
    "providerName": "OpenAI",
    "inputPrice": 0.000005,
    "outputPrice": 0.000015,
    "isEnabled": true
  }
]
```

## 3. 前端计费展示策略

前端页面 (`ModelsPage.tsx`) 采用以下展示转换逻辑：
*   **价格单位转换**：数据库中存储的是 `USD/Token` (非常小的数字)。
*   **展示格式**：前端通常展示为 `USD / 1M Tokens` 以提高可读性。
*   **辅助方法**：`formatPrice(price: number): string`
    *   `DisplayPrice = DBPrice * 1,000,000`

## 4. 核心逻辑：模型解析器

后端 `AiModelService.resolvePreferredEnabledModelId` 方法负责解析当前会话应使用的模型：
1.  **用户指定**：如果用户手动选择了某个已启用模型，则优先使用。
2.  **默认降级**：若未指定或已失效，则尝试选取当前供应商下第一个已启用的模型。
3.  **全局兜底**：若上述均无，则返回系统设置中的 `Default Model`。

## 5. 删除模型与会话自动降级（2026-04-28）

- 新增接口：`DELETE /api/models/{id}`。
- 删除模型时，后端会先查询引用该模型的会话（`chat_session.model_id`），并自动迁移到“默认且启用”的模型。
- 若系统中不存在可用默认模型，则回退到第一个启用模型；若仍不存在，则会话 `model_id` 置空（保留会话与消息）。
- 历史消息不会被删除，`chat_message.model_name` 作为快照继续保留，用于历史内容展示。
