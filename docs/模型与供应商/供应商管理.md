# 供应商管理 (Provider Management)

供应商管理模块负责对接各种大模型服务商（如 OpenAI, Anthropic, OpenRouter 等），并安全地存储其访问密钥及基础 URL。

## 1. 核心数据模型

### 数据库表：`provider`
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | BIGINT | 自增主键 |
| `name` | VARCHAR(255) | 供应商显示名称（如：OpenAI） |
| `api_key` | VARCHAR(255) | AES 加密后的 API Key |
| `base_url` | VARCHAR(255) | API 的基础 URL |
| `is_enabled` | BOOLEAN | 是否启用该供应商 |

## 2. 安全机制：AES 加密

系统对所有 API Key 进行静态加密。
*   **算法**：AES/ECB/PKCS5Padding
*   **配置项**：`aiagent.encryption.secret` (位于 `application.yml`)
*   **工具类**：`com.aiagent.util.EncryptionUtil`

后端逻辑流程：
1.  **保存**：接收前端 Plain Text -> `EncryptionUtil.encrypt()` -> 存入数据库。
2.  **使用**：从数据库读取 Cipher Text -> `EncryptionUtil.decrypt()` -> 发送 HTTP 请求。

## 3. API 接口设计

| 动作 | 路径 | 方法 | 说明 |
| :--- | :--- | :--- | :--- |
| 获取列表 | `/api/providers` | GET | 返回所有已配置的供应商（API Key 字段脱敏） |
| 创建/更新 | `/api/providers` | POST | 新增或编辑供应商信息 |
| 删除 | `/api/providers/{id}` | DELETE | 物理删除供应商及其关联的所有模型 |

### 请求示例 (POST)
```json
{
  "name": "OpenAI",
  "apiKey": "sk-...",
  "baseUrl": "https://api.openai.com/v1",
  "isEnabled": true
}
```

## 4. 前端实现

### 状态管理 (`providerStore.ts`)
使用 Zustand 维护全局供应商状态：
*   `providers`: 当前系统已加载的供应商列表。
*   `fetchProviders()`: 异步请求 API 并同步本地 Store。

### UI 交互 (`ModelsPage.tsx`)
在模型页面提供供应商配置弹窗：
1.  **脱敏显示**：在前端列表，`apiKey` 通常显示为 `********`。
2.  **输入控制**：当用户修改供应商但未输入新 Key 时，前端发送请求时不包含 `apiKey` 字段，后端保留原加密值。
