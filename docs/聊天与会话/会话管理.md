# 会话管理实现

Open Zen 提供了灵活的会话生命周期管理，支持复杂的分支、复制与偏好记忆策略。

## 核心 API

| 接口 | 方法 | 说明 |
| :--- | :--- | :--- |
| `GET /api/chat/sessions` | `listSessions` | 获取非临时且不属于特定项目的会话列表 |
| `POST /api/chat/sessions` | `createSession` | 新建会话，可指定 `agentId` |
| `PATCH /api/chat/sessions/{id}` | `updateSession` | 更新标题、模型、智能体或启用的工具列表 |
| `POST /api/chat/sessions/{id}/copy` | `copySession` | 克隆会话及所有消息 |
| `POST /api/chat/sessions/{id}/branch` | `branchSession` | 从某条消息处分支出新会话 |

## 关键功能实现

### 1. 复制与分支 (Branching)

- **实现原理 (ChatService.java)**：
  - `copySession`: 创建新 `ChatSession` 并克隆源会话的所有 `ChatMessage`。
  - `branchSession`: 传入 `messageId`，创建新会话并将源会话中该消息及之前的历史消息完整复制到新会话。
- **关联逻辑**：新会话通过 `parent_session_id` 和 `parent_message_id` 记录来源。

### 2. 草稿态与临时会话

- **草稿态 (startDraftSession)**：前端清空当前 `currentSessionId` 与消息列表，但保留用户当前的模型选择偏好，避免新建对话时重复配置。
- **临时会话 (is_temporary)**：
  - 发送请求时 `temporary: true`。
  - 临时会话不会出现在左侧的历史列表 (`listSessions` 时已通过 `is_temporary` 过滤)。
  - 用于一次性测试或“无痕”聊天。

### 3. 会话模型策略

- **进入会话 (selectSession)**：
  1. 优先尝试从 `messages` 列表中反转查找最后一条携带 `model_id` 的助手消息。
  2. 若无历史消息，则回退到 `chat_session.model_id`。
  3. 最终回退到系统默认启用的模型。
- **模型失效降级 (AiModelService)**：若模型被禁用，系统会自动将其替换为默认可用模型，并更新会话记录。

## 关键文件定位

- **前端**：`web/src/store/chatStore.ts` (核心逻辑: `selectSession`, `startDraftSession`)
- **后端**：`ChatService.java` (核心逻辑: `copySession`, `branchSession`, `getSessionInternal`)
- **数据库表**：`chat_session`
