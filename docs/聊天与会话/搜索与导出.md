# 搜索与导出实现

Open Zen 为会话提供了强大的内容检索和跨平台导出能力。

## 会话搜索

- **接口**: `GET /api/chat/sessions/search?keyword=...`
- **搜索范围**: 
  - **标题匹配**: 模糊搜索 `chat_session.title`。
  - **内容匹配**: 模糊搜索 `chat_message.content` (支持角色为 `user`, `assistant`, `tool` 的消息)。
- **合并策略 (ChatService.java)**：
  - 搜索结果按关联度（标题优先）和时间（最新优先）排序。
  - 命中消息内容时，后端通过 `buildSearchSnippet` 提取包含关键词的前后 60 字摘要，并标记匹配位置。
  - 结果对象 `ChatSessionSearchResultResponse` 标记匹配类型（`title`, `message`, `both`）。

## 导出会话

会话导出逻辑完全在前端实现，支持 Markdown 和 PDF 两种主流格式。

### 1. 导出 Markdown
- **逻辑 (ChatPage.tsx)**：
  - 使用 `buildSessionExportMarkdown` 将整个会话渲染为标准的 GFM 格式。
  - 消息间使用 `---` 分割。
  - 包含推理过程 (`思考过程` 章节) 与模型快照信息。
- **下载触发**：通过 `Blob` 结合 `a` 标签的 `download` 属性实现。

### 2. 导出 PDF
- **逻辑 (ChatPage.tsx)**：
  - 先调用 `buildSessionExportHtml` 将会话消息动态构造为完整的 HTML 文档（内嵌精美 CSS 样式）。
  - 推理内容展示为灰色背景的 `pre` 块，Markdown 正文使用 `ReactMarkdown` 的静态渲染版本。
  - **打印机制**：创建一个隐藏的 `iframe`，写入该 HTML，并调用 `window.print()`。
  - 用户可直接在浏览器打印对话框中选择“另存为 PDF”。

### 3. 分享会话
- **逻辑**：Open Zen 采用 URL 路由架构，当前会话链接格式为 `/chat/:sessionId`。
- **实现**：前端提供“复制链接”功能，支持用户直接将当前会话地址发送给他人（需拥有系统访问权限）。

## 关键文件定位

- **前端**：`web/src/pages/ChatPage.tsx` (导出函数: `buildSessionExportMarkdown`, `printHtmlAsPdf`)
- **后端**：`ChatService.java` (搜索函数: `searchSessions`)
- **搜索摘要工具**：`ChatService.buildSearchSnippet`
