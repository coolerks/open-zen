# 自动标题生成实现

为提升用户体验，Open Zen 会在会话首轮对话后自动异步生成具有语义的标题。

## 业务流程

1.  **触发时机**：前端 `sendMessage` 方法检测到当前为“新会话”且首条用户消息发送成功。
2.  **异步调用**：通过 `POST /api/chat/sessions/{id}/auto-title` 发起请求。
3.  **生成策略 (ChatService.java)**：
    - 后端使用当前会话选择的模型（或默认模型）调用大模型。
    - **提示词**：要求模型对用户的首条提问进行概括（限 6-10 字）。
    - **参数**：固定低温度 `temperature: 0.2` 以确保结果稳定。

## 失败降级链

生成标题的过程被设计为**非阻塞**且**容错**的，按以下顺序尝试确定最终标题：

1.  **模型生成**：模型返回的文本，经过 `normalizeGeneratedTitle` (去除引号、多余空行、截断至 100 字)。
2.  **首条提问截取**：若模型调用失败，直接截取用户首条问题的正文。
3.  **图片对话识别**：若首条消息仅包含图片，使用“图片对话”作为标题。
4.  **兜底方案**：若以上均不可用，保持默认的“新会话”。

## 并发冲突保护

前端 `chatStore` 在处理 `auto-title` 回包时，会检查：
- 当前页面是否仍处于该会话。
- 当前会话标题是否已被用户手动修改。
- 防止并发回包导致已生成的标题被回退。

## 关键文件定位

- **前端**：`web/src/store/chatStore.ts` (触发逻辑: `sendMessage`)
- **后端**：`ChatService.autoGenerateSessionTitleInternal` (降级链逻辑)
- **模型调用**：`ChatService.generateTitleByModel`
