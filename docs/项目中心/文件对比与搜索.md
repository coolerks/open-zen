# 文件对比与搜索 (Diff & Search)

文件对比与搜索是项目中心最强大的工具，为用户提供精确的代码审阅与高效的信息定位能力。

## 文件对比 (Diff View)

文件对比功能基于 **Monaco DiffEditor**，支持对两个文件的内容或两个不同版本的同一文件进行直观对比。

### 主要交互逻辑
- **多选对比**：在侧栏资源管理器中按住 `Ctrl` (Windows) / `Cmd` (Mac) 键点击，多选两项文件。
- **一键 Diff**：在选中的文件上右键点击，选择“对比选中项”。
- **双栏视图**：左侧显示源文件内容，右侧显示目标文件内容。
- **差异高亮**：精准标记行级别的添加、删除和修改，支持跨行比较和字符级别的细粒度差异。

### 应用场景
- **代码重构**：审阅重构前后的逻辑变化。
- **合并前预览**：在提交或回写文件前，确认变更内容。
- **版本比对**：支持将当前编辑中的文件与本地已保存的版本进行实时对比。

## 全局代码搜索 (Global Search)

全局搜索功能通过侧栏的搜索图标进入，支持在整个项目目录下执行快速检索。

### 核心功能
- **双重搜索模式**：
  - **文件名搜索**：按关键字快速过滤并列出匹配的文件名。
  - **内容搜索**：读取文件内容，查找匹配的代码行，并显示上下文片段。
- **.gitignore 支持**：
  - **默认遵循**：搜索过程会自动忽略 `.gitignore` 规则中定义的路径（如 `node_modules`, `dist`, `.git` 等）。
  - **按需放开**：搜索设置中提供“包含 .gitignore 忽略项”勾选框，允许用户在必要时搜索被忽略的文件。

### 技术实现
- **流式扫描**：前端通过 `ProjectFilesystemService` 的搜索接口向后端发送请求。
- **分块处理**：后端采用流式读取文件内容，并按行进行匹配，避免一次性加载过多文件导致内存溢出。
- **性能优化**：对于超过 1MB 的大文件，默认跳过内容搜索以提升速度（可在设置中调整阈值）。
- **结果高亮**：搜索结果列表中会高亮显示匹配的关键字，并附带所在行号。

## 高级过滤

- **文件类型过滤**：支持指定文件后缀名范围，如 `*.ts, *.tsx`。
- **区分大小写**：支持开关区分大小写的匹配逻辑。
- **正则表达式**：搜索框支持标准的正则表达式语法。
