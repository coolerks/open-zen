# 项目管理 (Project Management)

项目管理功能允许用户在 Open Zen 中高效地组织和切换不同的代码库。

## 项目元数据 (CRUD)

项目元数据存储在后端的 `project_item` 表中。每个项目定义如下：

- **ID**: UUID（格式：`project_uuid`）。
- **Name**: 项目名称。
- **Description**: 项目描述。
- **Root Dir Name**: 项目根目录的显示名称。
- **Real Dir Path**: 项目在本地文件系统中的真实绝对路径。

### 主要 API 接口
- `GET /api/projects`: 获取所有项目列表。
- `POST /api/projects`: 创建新项目。
- `PUT /api/projects/{id}`: 更新项目元数据或关联路径。
- `DELETE /api/projects/{id}`: 删除项目关联（不删除本地文件）。

## 文件夹选择器 (showDirectoryPicker)

项目关联过程依赖 **File System Access API** 提供的 `window.showDirectoryPicker()`：

1. **选择目录**：用户点击“新建项目”或“关联目录”时，触发浏览器原生的文件夹选择对话框。
2. **获取句柄**：浏览器返回一个 `FileSystemDirectoryHandle`。
3. **关联到项目**：前端将该句柄的元数据（如名称）以及用户手动指定的本地绝对路径发送到后端。

> **注意**：出于隐私考虑，Web 平台无法直接从句柄中读取绝对路径（取决于浏览器安全策略）。Open Zen 允许用户输入路径，或通过后端辅助定位。

## 前端存储方案

Open Zen 在前端采用了两级存储策略：

1. **localStorage** (`openzen.projects.last.real_dir.v1`):
   - 保存用户最后一次操作的本地目录路径。
   - 用于下次新建项目时提供路径补全建议。

2. **IndexedDB** (待扩展/可选):
   - 计划用于持久化存储 `FileSystemHandle`（文件句柄）。
   - 允许用户在页面刷新后无需再次点击授权即可恢复对本地目录的读写访问。

## 核心设计原则

- **仅保存目录句柄不上传代码**：后端仅记录本地路径，通过 `ProjectFilesystemService` 直接读取本地硬盘上的内容。这种方式确保了海量代码库的访问速度，同时避免了隐私风险。
- **UUID 路由**：项目中心通过 `/projects/:projectId` 进行路由切换，确保在不同项目间无缝切换，同时保持编辑器状态（标签页、搜索关键字）。
