# 资源管理器 (File Explorer)

资源管理器为用户提供 VS Code 风格的文件浏览体验，支持目录树操作、图标映射、语言自动识别等功能。

## 核心功能

### 1. VS Code 风格文件树
- **层级展现**：递归展示项目根目录及其子目录的文件结构。
- **目录展开/折叠**：点击目录即可展开或折叠。
- **文件选择**：单击文件即可在编辑器中打开对应的标签页。
- **上下文菜单**：右键点击文件或目录可执行新建文件、新建目录、重命名、删除、刷新等操作。

### 2. 文件图标映射
资源管理器通过 `web/src/utils/projectIcons.ts` 实现文件图标的自动匹配：

- **技术方案**：使用 `import.meta.glob` 加载 **Material Icon Theme** 的 SVG 图标资源。
- **映射逻辑**：
  - **按文件名**：如 `package.json` 对应 npm 图标，`dockerfile` 对应 Docker 图标。
  - **按扩展名**：如 `.ts` 映射到 TypeScript 图标，`.py` 映射到 Python 图标。
  - **默认图标**：对于无法识别的文件类型，使用通用的“文件”或“文件夹”图标。

### 3. 语言识别与代码高亮
在打开文件时，资源管理器会自动识别文件对应的编程语言：

- **扩展名映射**：
  - `.js`, `.jsx`, `.ts`, `.tsx` -> `javascript` / `typescript`
  - `.py` -> `python`
  - `.md`, `.markdown` -> `markdown`
  - `.java`, `.go`, `.rs` 等 -> 对应语言。
- **Monaco Language**：识别出的语言直接传递给 **Monaco Editor**，实现精准的语法高亮和基本的代码提示。

### 4. 目录状态持久化
资源管理器维护一个 `expandedMap` 状态，记录用户当前展开的所有目录路径。

- **动态加载**：仅当目录被展开时，前端才会向后端请求该目录下的子项列表 (`ProjectFsDirectoryResult`)。
- **状态恢复**：切换项目或刷新页面后，资源管理器会尝试恢复之前的展开状态。

## 技术细节

- **懒加载 (Lazy Loading)**：前端不会一次性拉取整个项目树，而是按需（展开目录时）请求子目录内容，极大地降低了大项目的加载耗时。
- **拖放操作 (Drag & Drop)**：支持将文件或目录拖动到新的父目录下实现移动操作。同时支持将文件拖放到编辑区的左/右分栏以打开。
- **.gitignore 过滤**：资源管理器在渲染时默认遵循根目录下的 `.gitignore` 规则，隐藏被忽略的文件和目录（可在搜索栏配置中开启可见性）。
