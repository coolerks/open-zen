# 编辑器与标签页 (Editor & Tabs)

编辑器与标签页功能为用户提供流畅的代码阅读、编辑与窗口布局体验。

## 核心编辑器 (Monaco Editor)

项目中心内置 **Monaco Editor**（VS Code 的核心编辑器组件），提供以下能力：

- **代码预览**：默认以只读模式（Read-only）打开文件，确保本地文件不被误改。
- **语法高亮**：支持 JavaScript、TypeScript、Python、Java、Go、Rust、HTML、CSS、Markdown 等数十种常见语言。
- **自动检测**：基于文件名和扩展名自动匹配 Monaco 语言 ID。
- **编辑回写**：对于具有写权限的项目，支持将编辑后的内容实时保存到本地文件。

## 多标签页管理 (Tabs Management)

标签页状态由 `web/src/pages/ProjectsPage.tsx` 中的 `openTabs` 和 `groups` 状态共同管理：

- **基本操作**：
  - **打开/关闭**：点击侧栏文件打开标签页，点击标签页右上角 `x` 关闭。
  - **激活/切换**：点击标签页头部在不同文件间快速切换。
  - **重排/拖拽**：支持通过拖拽标签页头部来改变其在当前组内的顺序，或将其拖动到另一编辑组。
- **右键菜单**：
  - **关闭**：关闭当前选中的标签页。
  - **关闭其他**：仅保留当前标签页，关闭本组内所有其他页。
  - **全部关闭**：关闭本组内的所有标签页。
  - **向左/向右拆分**：将当前文件在另一个编辑组内打开，实现分屏对比。

## 双栏编辑区 (Split View)

编辑区支持双栏（左、右分栏）布局，旨在提高多文件协同工作的效率：

- **灵活分栏**：
  - **左右分栏**：两个独立的编辑组，各自拥有独立的标签页列表和激活状态。
  - **拖拽调整宽度**：分栏中间有可拖拽的调整条，支持自定义两栏的比例。
- **跨组交互**：
  - **文件拖放**：可以将侧栏的文件直接拖放到左栏或右栏来打开。
  - **组间移动**：可以将左栏的标签页拖动到右栏，反之亦然。

## 预览模式

针对特定文件类型，编辑器提供专门的预览增强：

- **Markdown 预览**：支持 GFM 语法、公式（KaTeX）、图表（Mermaid），可一键切换源码/预览模式。
- **图片/SVG 预览**：对于图片和 SVG 文件，提供缩放、自适应视图，并显示文件元数据（尺寸、大小）。
- **二进制文件**：对于无法直接编辑的二进制文件（如 PDF, Zip, Executable），显示占位符或简要元数据信息。
