# 应用中心功能文档

应用中心用于管理由 AI 在对话中生成的网页应用或脚本代码。它提供应用收藏、在线编辑、版本回退及来源追溯等功能。

## 1. 从聊天代码块保存应用

当 AI 生成包含 `html` 等可运行代码块时，用户可将其一键保存到应用中心。

### 1.1 SourceKey 生成规则
每个应用关联一个唯一的 `sourceKey`，用于在后端进行幂等校验：
- **生成公式**: `messageId + "_" + codeBlockIndex`
- **示例**: `1024_0` 表示 ID 为 1024 的消息中第 1 个代码块。
- **作用**: 确保同一对话中的同一个代码块不会被重复收藏。

### 1.2 去重约束
系统通过两层校验防止重复：
1. **数据库层**: `app_center_item` 表设有 `uk_app_source_key` 唯一索引。
2. **服务层**: `AppCenterService.create` 在插入前先查询 `existsBySourceKey`，若冲突则抛出“该代码块已添加到应用中心”异常。

### 1.3 来源信息记录
保存时，系统会为应用建立详尽的上下文快照：
- **来源会话**: 记录 `sourceSessionId` 及其标题快照 `sourceSessionTitle`。
- **来源消息**: 记录 `sourceMessageId`。
- **生成模型**: 记录 `sourceModelId` 及其名称快照 `sourceModelName`。
- **代码快照**: 除了当前代码外，还会记录 `original_code_content` 原始快照，供后续“重置”使用。

## 2. 应用管理 (CRUD)

系统通过标准的 RESTful API 提供管理功能。

### 2.1 API 定义
- **获取列表**: `GET /api/apps`
- **获取详情**: `GET /api/apps/{id}`
- **创建应用**: `POST /api/apps`
- **更新应用**: `PUT /api/apps/{id}`
- **删除应用**: `DELETE /api/apps/{id}`

### 2.2 应用图标
支持两种图标表现形式：
- **Emoji**: 内置 10 种常用表情符号（如 🚀, 📊, 🛠️ 等）供用户选择。
- **Image**: 用户可上传本地图片，系统将其转为 `DataURL` 存储在 `icon_value` 字段中。

## 3. 代码编辑与预览

### 3.1 Monaco Editor 集成
编辑器集成 `Monaco Editor` (通过 `@monaco-editor/react`)，支持：
- 代码高亮（根据 `language` 字段自动切换）。
- 实时编辑保存。
- 全屏编辑模式：适合大体量 HTML 文档开发。

### 3.2 版本对比 (Diff)
编辑器内置 `DiffEditor` 模式：
- **基线**: 上次保存的 `lastSavedCodeContent`。
- **修改**: 当前正在编辑的内容。
- **用途**: 保存前快速核对本次改动点。

### 3.3 重置代码
如果用户在编辑过程中改乱了代码，可使用“重置到原始代码”功能：
- **逻辑**: 读取数据库中的 `original_code_content` 字段。
- **回退**: 覆盖当前编辑区内容，恢复为 AI 最初生成的版本。

### 3.4 应用预览
支持一键打开应用预览：
- **机制**: 在前端通过 `URL.createObjectURL` 将代码内容封装为临时 Blob URL。
- **展示**: 在新标签页中通过 Iframe 或直接加载该 URL 进行实时渲染。

## 4. 其它功能

### 4.1 手动创建应用
除了从聊天中保存外，用户也可以点击“新增应用”手动编写代码：
- **SourceKey**: 生成 `manual-UUID` 格式的标识符。
- **模版**: 自动填充标准的 HTML5 骨架模版。

### 4.2 来源追溯
在应用中心列表页，用户可点击“定位来源”：
- **跳转**: 跳转至 `/chat/{sessionId}?messageId={messageId}`。
- **交互**: 进入聊天页后，系统会自动滚动到对应消息并高亮显示，方便查看生成背景。

### 4.3 未保存修改保护
为防止误操作丢失工作量：
- **检测**: 监控 `hasUnsavedCodeChanges` 状态。
- **确认**: 当用户在代码有变动且未保存时尝试关闭对话框，系统会弹出确认提示（`window.confirm`）。
