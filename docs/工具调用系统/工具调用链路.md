# 工具调用链路 (Tool Execution Pipeline)

工具调用的完整生命周期涉及模型推理、后端调度执行和上下文反馈的闭环，主要由 `ChatService` 驱动。

## 递归调用逻辑

系统采用 **递归 (Recursive)** 的方式处理工具调用：

1.  **用户输入**: 客户端发送包含“白名单工具”的消息。
2.  **模型决策**: 大模型判断是否需要调用工具。
    - 若需要，返回 `tool_calls` 列表（包含函数名和参数）。
    - 若不需要，直接返回普通文本回复。
3.  **后端分发 (Dispatching)**:
    - 后端解析 `tool_calls`。
    - **检查权限**：若工具非 `bypassUserApproval` 且尚未获得用户授权，则记录调用并中断输出（详见[用户授权流](./用户授权流.md)）。
    - **反射执行**：对于已授权的操作，后端根据函数名在 `ToolRegistry` 中找到对应的 Bean 和 Method，通过反射机制传入 JSON 参数并执行。
4.  **结果回馈 (Feedback Loop)**:
    - 将工具执行结果作为 `tool` 角色的消息加入上下文。
    - **递归调用**：再次将更新后的上下文发送给大模型，模型根据执行结果决定是“继续调用下一个工具”还是“生成最终回答”。

## SSE (Server-Sent Events) 协议交互

后端通过 SSE 实时向前端同步状态：

- `tool_call`: 发送模型决策生成的工具调用详情。
- `tool_result`: 发送后端执行工具后的原始返回结果。
- `toolApprovalRequired`: **中断信号**。通知前端显示授权卡片。
- `content`: 普通文本消息片段。

## 关键文件路径

- **核心执行循环**: `server/src/main/java/com/aiagent/service/ChatService.java` (方法: `runCompletionWithTools`)
- **工具分发处理**: `server/src/main/java/com/aiagent/service/tool/ToolExecutor.java`
- **消息模型定义**: `server/src/main/java/com/aiagent/model/ChatMessage.java`
