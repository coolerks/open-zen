# 扩展新工具指南 (Extending New Tools)

本指南旨在指导开发者如何在 Open Zen 系统中添加一个全新的 AI 工具。只需 4 个步骤，即可完成从后端逻辑开发到前端生效的全过程。

## 步骤 1: 创建 Java 工具类

在 `server/src/main/java/com/aiagent/service/tool/impl/` 目录下创建一个新类。

**核心要求**:
1.  使用 `@Component` 将其注册为 Spring Bean。
2.  使用 `@AiTool` 标记该类，并提供全局描述。

```java
@Component
@AiTool(name = "WeatherTool", description = "用于查询全球主要城市的实时天气情况")
public class WeatherTool {
    // ...
}
```

## 步骤 2: 实现工具方法并添加注解

编写具体的执行逻辑，并使用 `@AiToolMethod`、`@AiToolParam` 和 `@AiToolResult` 进行详尽描述。

```java
@AiToolMethod(
    name = "getCurrentWeather",
    description = "获取指定城市的当前温度、湿度和天气状况",
    bypassUserApproval = true // 读操作通常可以设为 true
)
@AiToolResult(description = "包含天气信息的 JSON 字符串")
public String getCurrentWeather(
    @AiToolParam(name = "city", description = "城市名称，如 'London', 'Beijing'", required = true) String city,
    @AiToolParam(name = "unit", description = "温度单位：'celsius' 或 'fahrenheit'", required = false) String unit
) {
    // 1. 调用第三方 API (如 OpenWeather)
    // 2. 返回结果
    return String.format("{\"city\": \"%s\", \"temp\": 25, \"unit\": \"%s\"}", city, unit != null ? unit : "celsius");
}
```

## 步骤 3: 自动扫描与注册

你**不需要**手动在任何地方注册该工具。
- 系统启动时，`ToolAnnotationScanner` 会自动识别所有带有 `@AiTool` 注解的 Bean。
- 它会自动生成 JSON Schema 并将其存入 `ToolRegistry`。

## 步骤 4: 前端刷新与使用

1.  **重启后端服务**: 确保新工具被加载。
2.  **进入前端页面**: 在聊天输入框左侧点击 **“+”** 按钮。
3.  **刷新工具列表**: 点击设置中的“刷新工具列表”或重新进入页面，你将在列表中看到 `WeatherTool`。
4.  **启用工具**: 勾选 `WeatherTool`。
5.  **开始对话**: 输入“北京今天天气怎么样？”，模型将自动调用你的 `getCurrentWeather` 方法。

## 最佳实践与注意事项

1.  **描述胜过代码**: AI 是否调用工具完全取决于你的 `@AiToolMethod` 的 `description` 写得好不好。描述中应明确说明“在什么情况下该调用此方法”。
2.  **安全性**: 任何具有副作用（写文件、删数据、发邮件、执行命令）的操作，必须设置 `bypassUserApproval = false`。
3.  **错误处理**: 在工具方法内部捕获异常并返回友好的错误信息字符串。如果抛出未捕获异常，系统会将其记录为工具执行失败。
4.  **参数类型**: 目前主要支持基本类型（String, int, boolean, double）。复杂对象建议通过 JSON 字符串进行传递和解析。
