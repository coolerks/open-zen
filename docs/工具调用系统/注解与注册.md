# 注解与注册 (Annotation & Registration)

工具调用系统的核心逻辑在于如何将 Java 类和方法转换为 AI 可理解的 **JSON Schema**。这一过程主要由 `@AiTool` 注解体系和 `ToolAnnotationScanner` 扫描器完成。

## 注解体系

系统定义了一套自定义注解，用于声明工具的元数据：

1.  **`@AiTool` (类级)**:
    - 用于标记一个类为 AI 工具。
    - 属性 `name`: 工具的唯一名称（如果未指定，默认使用类名）。
    - 属性 `description`: 工具的全局描述。
2.  **`@AiToolMethod` (方法级)**:
    - 标记类中的具体执行方法。
    - 属性 `name`: 方法名。
    - 属性 `description`: 描述该方法的功能及适用场景（AI 依赖此描述进行调用决策）。
    - 属性 `bypassUserApproval`: **关键属性**。若为 `true`，则调用此工具无需用户授权。默认通常为 `false`（敏感操作需授权）。
3.  **`@AiToolParam` (参数级)**:
    - 描述方法参数。
    - 属性 `name`: 参数名（对应 JSON 中的 key）。
    - 属性 `description`: 参数的具体含义及格式要求。
    - 属性 `required`: 是否必填。
4.  **`@AiToolResult` (返回描述)**:
    - 描述方法返回值的含义。

## 扫描与注册过程

### 1. Spring Bean 自动注入
所有被 `@AiTool` 标记的类必须首先是一个 **Spring Bean**（通常配合 `@Component` 或 `@Service`）。

### 2. 工具扫描器 (`ToolAnnotationScanner`)
在系统启动或需要刷新工具列表时，`ToolAnnotationScanner` 会执行以下步骤：
- 遍历 Spring 上下文中所有被 `@AiTool` 标记的 Bean。
- 利用反射机制提取类、方法及参数上的元数据。
- **核心逻辑**：将元数据转换为 OpenAI 标准的 `Function Definition` (JSON Schema)。

### 3. 注册表管理 (`ToolRegistry`)
`ToolRegistry` 是工具在内存中的存储仓库：
- **`registerTool()`**: 将扫描到的工具及其方法存储在内部 Map 中。
- **`getToolsForSession()`**: 根据用户在前端勾选的“白名单”（Session 级别配置），过滤并返回可供模型调用的工具子集。

## 关键文件路径

- **注解定义**: `server/src/main/java/com/aiagent/annotation/tool/`
- **扫描逻辑**: `server/src/main/java/com/aiagent/service/tool/ToolAnnotationScanner.java`
- **注册中心**: `server/src/main/java/com/aiagent/service/tool/ToolRegistry.java`
