# 内置工具 (Built-in Tools)

Open Zen 预置了一系列核心工具，用于增强 AI 的感知与执行能力。所有内置工具均位于后端 `server/src/main/java/com/aiagent/service/tool/impl/` 目录下。

## 1. 文件操作工具 (`FileOperationTool`)
- **功能**: 支持模型在授权目录下进行文件的读取、写入、列表查询。
- **关键方法**:
    - `readFile(path)`: 读取指定文件的内容。
    - `writeFile(path, content)`: 将内容写入指定路径（覆盖模式）。
    - `listDirectory(path)`: 列出目录下的所有子文件和文件夹。
- **安全性**: 该工具通常不设 `bypassUserApproval = true`，所有写操作必须经过用户确认。

## 2. 网络搜索工具 (`SerpSearchTool`)
- **功能**: 调用外部搜索引擎（如 SerpAPI）获取实时网络信息。
- **关键方法**:
    - `search(query)`: 传入关键词，返回搜索结果摘要及链接。
- **特性**: 常设为 `bypassUserApproval = true`（纯读操作），允许模型自主查询。

## 3. 命令行工具 (`TerminalTool`)
- **功能**: 在受限的环境中执行 shell 命令（如 `ls`, `grep`, `pwd`）。
- **关键方法**:
    - `execute(command)`: 执行单条指令并捕获 stdout/stderr。
- **风险提示**: 此工具具备极高风险，默认严格限制执行命令的白名单，且必须强制用户授权。

## 4. 系统信息工具 (`SystemInfoTool`)
- **功能**: 获取当前服务器的 CPU、内存、操作系统版本等元数据。
- **关键方法**:
    - `getDiagnostics()`: 返回系统健康状态 JSON。

## 5. 数据库查询工具 (`DatabaseQueryTool`)
- **功能**: (实验性) 根据配置连接指定的只读数据库，执行 SQL 查询。
- **关键方法**:
    - `query(sql)`: 执行 SELECT 语句并返回结果集。

---

**注**: 开发新工具时，建议参考 `FileOperationTool.java` 的实现，它是最标准的工具范式。
