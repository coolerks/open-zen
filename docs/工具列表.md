# 项目中心工具列表

本文档描述 **仅项目中心聊天可用** 的 Code Agent 工具。  
这些工具在后端统一受限于当前项目根目录，无法访问项目外路径。

## 通用约束

- 所有工具执行结果都会作为下一轮 `tool_result` 回传给 LLM。
- 所有路径参数均为“项目内相对路径”，后端会做越界校验。
- 普通聊天（`/api/chat/*`）不会下发这些项目工具。
- 项目聊天（`/api/projects/{projectId}/chat/*`）会按会话工具配置下发。

## 1. `bash`

在项目目录执行 shell 命令。

### 输入参数

- `command: string` 必填，要执行的命令。
- `timeoutSec: integer` 可选，默认 `30`，范围 `1~180`。
- `maxOutputKb: integer` 可选，默认 `256`，范围 `16~2048`。

### 输出

- 返回命令、工作目录、退出码（或超时状态）和合并后的标准输出/错误输出。
- 若输出超限，会提示已截断。

## 2. `read`

读取文件内容，支持分段读取大文件。

### 输入参数

- `path: string` 必填，文件相对路径。
- `offset: integer` 可选，起始行号（1-based），默认 `1`。
- `limit: integer` 可选，读取行数，默认 `2000`，最大 `2000`。

### 输出

- 返回行号 + 文本内容。
- 若未读完整，会追加提示：可传 `offset` 继续读取。
- 若单行超过 `50KB`，返回提示并拒绝返回该次文件内容。

### 大文件行为

当文件很大（例如 15000 行）时，`read` 不报错：

1. 第一次返回 `1~2000` 行。
2. 末尾附带“继续读取”提示。
3. LLM 可自行决定是否继续调用 `read`。

## 3. `edit`

通过精确字符串替换修改现有文件（主要代码编辑方式）。

### 输入参数

- `path: string` 必填，文件相对路径。
- `search: string` 必填，待替换的原始文本（精确匹配）。
- `replace: string` 必填，替换文本。
- `replaceAll: boolean` 可选，默认 `false`，是否替换全部匹配项。

### 输出

- 返回替换成功信息、替换数量、目标文件路径。
- 未找到匹配时返回明确失败原因。

## 4. `write`

创建新文件或覆盖已有文件。

### 输入参数

- `path: string` 必填，目标文件路径。
- `content: string` 必填，写入内容。
- `createParents: boolean` 可选，默认 `true`，是否自动创建父目录。

### 输出

- 返回写入成功信息、目标路径与写入字节数。

## 5. `grep`

用正则搜索文件内容。

### 输入参数

- `pattern: string` 必填，正则表达式。
- `glob: string` 可选，文件过滤模式，默认 `**/*`。
- `path: string` 可选，起始目录，默认项目根目录。
- `ignoreCase: boolean` 可选，默认 `false`。
- `limit: integer` 可选，默认 `200`，最大 `1000`。

### 输出

- 返回命中条目（`文件:行号 | 片段`）。
- 返回扫描统计与截断信息（达到 `limit` 时）。

## 6. `glob`

按 glob 模式匹配路径，并按修改时间倒序返回。

### 输入参数

- `pattern: string` 必填，glob 表达式（如 `src/**/*.ts`）。
- `path: string` 可选，起始目录，默认项目根目录。
- `limit: integer` 可选，默认 `200`，最大 `1000`。
- `includeDirectories: boolean` 可选，默认 `false`。

### 输出

- 返回匹配路径列表（`file/dir + 路径`）。
- 返回命中数量与是否截断。

## 7. `list`

列出目录内容，支持过滤与递归。

### 输入参数

- `path: string` 可选，起始目录，默认项目根目录。
- `glob: string` 可选，默认 `**/*`。
- `recursive: boolean` 可选，默认 `false`。
- `includeHidden: boolean` 可选，默认 `false`。
- `includeFiles: boolean` 可选，默认 `true`。
- `includeDirectories: boolean` 可选，默认 `true`。
- `limit: integer` 可选，默认 `200`，最大 `2000`。

### 输出

- 返回每个条目的类型、相对路径、大小（文件）和修改时间。
- 返回扫描数量、匹配数量、是否截断。

## 设计说明

- 工具返回值是 LLM 的下一轮输入，这决定了结果文本要可读、可继续推理。
- `read` 的分页和超长行保护是为了避免一次返回过多上下文，保证稳定性。
- `bash` 的超时与输出上限用于限制风险与资源占用。
