# 快速启动

本指南将帮助你从零开始部署并启动 Open Zen 项目。

## 环境要求
- **Java**: 21 或更高版本
- **Node.js**: 18 或更高版本
- **Maven**: 3.8 或更高版本
- **浏览器**: 建议使用 Chromium 内核浏览器（Chrome, Edge, Brave 等），以支持项目中心的 File System Access API。

## 启动指南

### 1. 后端服务启动
1. 进入后端目录：`cd server`
2. 运行测试并启动应用：`mvn clean test && mvn spring-boot:run`
3. 验证启动：访问 `http://localhost:8080/h2-console` 确认数据库可连接（默认 JDBC URL: `jdbc:h2:file:./data/aiagent`）。

### 2. 前端应用启动
1. 进入前端目录：`cd web`
2. 安装依赖：`npm install`
3. 启动开发服务器：`npm run dev`
4. 验证启动：访问 `http://localhost:5173`。

## 首次使用流程
1. **配置供应商**：在侧栏进入“模型管理” (`/models`)，点击“新增供应商”，填写 API Key 等信息。
2. **添加模型**：在模型列表中新增可用模型（或通过“模型发现”功能自动获取）。
3. **开始对话**：回到“聊天”页，选择刚才配置的模型，即可开始流式交互。

## 配置说明

### `application.yml` 关键配置
- `server.port`: 后端服务端口，默认为 `8080`。
- `spring.datasource.url`: H2 数据库文件路径。默认为当前目录下的 `./data/aiagent`。
- `spring.h2.console.path`: H2 管理控制台路径，默认为 `/h2-console`。
- `aiagent.encryption.secret`: API Key 的 AES 加密密钥。**生产环境下建议修改为 32 位随机字符串**。

## 生产部署建议
1. **前端构建**：使用 `npm run build` 生成静态文件。
2. **反向代理**：使用 Nginx 托管前端静态资源，并将 `/api/` 路径反向代理至后端 `8080` 端口。
3. **后端运行**：将后端打包为 JAR 包 (`mvn package`)，并在服务器上以守护进程方式运行。
4. **数据备份**：定期备份 `server/data/` 目录下的 H2 数据库文件。
