# 智能体管理设计文档 (Agent Management)

本模块旨在为 Open Zen 聊天平台提供灵活的 AI 身份定义能力，通过自定义智能体（Agent）为不同场景配置个性化的提示词与头像。

## 1. 核心模型

### 1.1 数据库结构 (custom_agent)
```sql
CREATE TABLE IF NOT EXISTS custom_agent (
    id            BIGINT AUTO_INCREMENT PRIMARY KEY,
    name          VARCHAR(100) NOT NULL, -- 智能体名称
    description   VARCHAR(500),          -- 描述信息
    system_prompt CLOB         NOT NULL, -- 系统提示词 (System Prompt)
    avatar_type   VARCHAR(20),           -- 头像类型: emoji/image
    avatar_value  CLOB,                  -- 头像内容: emoji 字符或 dataURL/图片地址
    is_default    BOOLEAN NOT NULL DEFAULT FALSE, -- 是否为默认智能体
    enabled       BOOLEAN NOT NULL DEFAULT TRUE,  -- 是否启用
    created_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 2. 默认智能体特殊逻辑

系统确保始终存在且仅存在一个“默认智能体”，该智能体具有以下约束：

- **强制存在**：每次列表查询或新建操作前，后端会自动校验默认智能体的存在，缺失时自动按内置模板（`你是默认智能体...`）创建。
- **归一化保证**：如果数据库中意外出现多个 `is_default=true` 的条目，系统在加载时会自动保留最早的一个，并纠正其余条目的 `is_default` 标识。
- **锁定名称**：默认智能体的名称固定为“默认”，禁止通过 API 修改其名称。
- **保留名称约束**：系统禁止任何自定义智能体使用“默认”作为名称。
- **不可禁用/删除**：默认智能体的 `enabled` 固定为 `true`，禁止删除。

## 3. 头像配置系统

智能体支持三种头像模式，配置灵活且易于展示：

| 类型 | 存储值 (`avatar_value`) | 前端展示 |
| :--- | :--- | :--- |
| **None** (AI) | `null` | 显示固定文本 `AI` 气泡 |
| **Emoji** | 字符串 (如 `🤖`) | 居中显示 Emoji 的圆形气泡 |
| **Image** | DataURL 或图片 URL | 完整裁剪显示的圆形图片 |

前端通过 `fileToDataUrl` 将本地上传的图片转换为 Base64 字符串持久化到后端。

## 4. 消息快照机制

为了防止因智能体信息的变更（如改名或修改头像）导致历史对话记录显示异常，Open Zen 采用了“消息级智能体快照”设计：

- **生成快照**：在 `ChatService` 发送或流式生成消息时，会将当前使用的智能体元数据（ID、名称、头像类型、头像内容）同步写入 `chat_message` 表的快照字段。
- **稳定展示**：前端渲染历史消息时，优先读取 `ChatMessage` 实体中的快照字段。即使原智能体已被修改或删除，历史对话中的 AI 形象仍保持发送时的状态。
- **旧数据处理**：对于快照字段为空的旧消息，系统将固定回退为 `AI` 默认形象。

## 5. 故障容错与边界处理

- **删除容错**：若用户删除了某个正在被草稿态会话使用的智能体，前端会在发送消息前进行有效性校验。若原智能体 ID 失效，自动重置并回退到系统默认智能体。
- **降级策略**：加载会话时，若会话关联的智能体不可用，系统会自动寻找可用的模型并挂载默认智能体，确保用户始终能开启对话。

## 6. API 定义

### 6.1 智能体管理
- `GET /api/agents`: 获取全部智能体（默认智能体排在首位）。
- `GET /api/agents/enabled`: 获取已启用的智能体列表（用于下拉选择）。
- `POST /api/agents`: 创建新智能体。
- `PUT /api/agents/{id}`: 更新智能体（默认智能体禁止修改名称与启用状态）。
- `PATCH /api/agents/{id}/toggle`: 切换启用/禁用状态。
- `DELETE /api/agents/{id}`: 删除智能体（默认智能体禁止删除）。
